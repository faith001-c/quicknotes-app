# QuickNotes

QuickNotes is a simple note-taking web app built with HTML, CSS and JavaScript. You can add short notes, give each one a category, search through them and delete the ones you no longer need. Your notes are saved in the browser, so they are still there after you refresh the page.

## Features

- Add a note with a category: Personal, Work or Study
- Each category has its own coloured left border (teal, dark red and blue)
- Validation: empty notes and notes over 200 characters show an error message
- Delete any note with its own Delete button
- A live note count ("You have no notes yet.", "You have 1 note.", "You have N notes.")
- Search notes as you type (not case-sensitive), with a message when nothing matches
- Notes are saved in localStorage and survive a page refresh
- Responsive layout: the form stacks vertically on screens 600px wide or narrower

## How to run

1. Download or clone this repository.
2. Open index.html in any web browser.

No installation or build step is needed.

## Technologies used

- HTML5 (semantic tags and labelled form controls)
- CSS3 (Flexbox, cards and a media query)
- JavaScript (DOM, events, arrays and localStorage)

## Project structure

- index.html - page structure
- style.css - styling and responsive layout
- script.js - add, delete, search, validation, count and saving
- README.md - project description
